# LearningHub – Responsive Educational Website

LearningHub is a responsive educational website designed to provide a simple, user-friendly, and engaging learning experience.

The project was developed using HTML, CSS, and JavaScript, with a focus on responsive design, clean user interface, and interactive web functionality.

[View LearningHub Live](https://hamzatech151.github.io/LearningHub/)

---

Technologies Used
* HTML5
* CSS3
* JavaScript
* Responsive Web Design

---

Features:
* Responsive design for different screen sizes
* Clean and user-friendly interface
* Interactive JavaScript functionality
* Easy navigation
* Compatible with desktop, tablet, and mobile devices
* Educational-focused website structure

Project Structure:

```text
LearningHub/
│
├── index.html      # Main webpage
├── style.css       # Website styling
├── script.js       # JavaScript functionality
└── README.md       # Project documentation
```

---

How to Run Locally:
1. Clone the repository:

```bash
git clone https://github.com/HamzaTech151/LearningHub.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation or dependencies are required.
